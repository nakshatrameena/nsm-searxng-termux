# NSM SearXNG Termux

Run a self-hosted SearXNG search API on Android using Termux and Ubuntu.

## Features
- Self-hosted web search API
- JSON results for AI agents and RAG
- No per-request SearXNG API fee

## API endpoint

http://127.0.0.1:8080/search?q=example&format=json

## Important
Search engines used by SearXNG may impose rate limits.
